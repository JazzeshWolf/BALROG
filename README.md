# BALROG

Evidence-first research framework for **buying** NSE/BSE options (NIFTY,
BANKNIFTY, SENSEX and ~157 F&O stocks), and the `buyConviction` scoring engine
built only from what survives out-of-sample testing after costs.

- `research/` — data-reality report, pre-registered hypotheses, scripts, trials log
- `data/` — dataset schemas (data files are not committed)
- `engine/` — `buyConviction` scoring engine + tests
- `report/` — chart-led research report

Start with `CLAUDE.md` (mission, conventions, evidence bars) and `STATE.md`
(current phase, decisions, file map).
